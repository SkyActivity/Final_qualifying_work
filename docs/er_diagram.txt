======================================

Entities (tables)
-----------------
1) ApplicantRecord
   - code (Text)
   - specialty (Char)
   - education_level (Char)
   - learning_form (Char)
   - total_students (Integer)
   - budget_rf (Integer)

2) ApplicantMapRecord

3) StudentRecord
   - fio (Char)

   - specialty (Char)
   - learning_form (Char)
   - education_level (Char)

Relationships
-------------
There are no explicit foreign keys in the current schema.
Logical links used by the app:
- ApplicantMapRecord <-> StudentRecord
  Matching by (city, region) to show map statistics.
- ApplicantRecord <-> StudentRecord
  Matching by specialty metadata (code, specialty, learning_form, education_level, year)
  for aggregated charts.
