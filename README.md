# VisualData

Веб‑приложение для анализа и визуализации данных об абитуриентах, направлениях
подготовки и регионах. Проект объединяет загрузку данных из Excel, интерактивные
графики, карту и аналитические отчеты по годам, направлениям и регионам.

## Демо

Локальный запуск: `http://127.0.0.1:8000/`.

## Возможности

- Дашборд с ключевыми показателями (итоги, средний балл, регионы).
- Интерактивные графики (bar/line/scatter) с фильтрами.
- Карта распределения по регионам и городам.
- Аналитика по годам, направлениям и регионам.
- Экспорт данных карты в CSV.
- Загрузка данных из Excel прямо в интерфейсе.

## Deploy to GitHub Pages

Этот проект — серверное Django‑приложение. GitHub Pages может хостить только
статический контент, поэтому мы публикуем документацию/скриншоты.

1. Убедитесь, что есть папка `docs/` (создана в репозитории).
2. В GitHub откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите:
   - **Source**: Deploy from a branch  
   - **Branch**: `main` / `/docs`
4. Сохраните настройки и дождитесь публикации.

URL будет вида: `https://<username>.github.io/<repo>/`.

## Форматы данных

### 1) Единый файл данных (`/dataapp/upload/data/`)

Порядок колонок:
1. `ФИО`  
2. `Пол` (`М`/`Ж`)  
3. `Дата рождения`  
4. `Город`  
5. `Область`  
6. `Баллы ЕГЭ по математике`  
7. `Баллы ЕГЭ по русскому языку`  
8. `Название профильного предмета`  
9. `Баллы профильного предмета`  
10. `Код`  
11. `Специальность`  
12. `Форма обучения`  
13. `Уровень образования`  
14. `Проходной балл по ЕГЭ на специальность`  
15. `Кол-во бюджетных мест`  
16. `Кол-во платных мест`  
17. `Год поступления`  

### 2) Данные для карты (`/dataapp/upload/map/`)

Порядок колонок:
1. `city` — город  
2. `region` — регион  
3. `specialty_code` — код специальности (должен существовать в базе)  
4. `count` — количество абитуриентов  

Примерные файлы лежат в папке `uploads/`.

Шаблон‑пример: `uploads/Data.xlsx`.

## Примечания

- Геокодинг выполняется через Nominatim (OpenStreetMap), требуется интернет.
- Для корректной карты сначала загрузите данные по специальностям,
  затем — данные по карте.
